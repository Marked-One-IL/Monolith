# Monolith
Monolith is a compiler for a language of the same name that targets x86 (32-bit Windows).

The language is loosely inspired by:
- C (execution model and low-level behavior)
- Python (syntax style)

## Status
This project will (probably) not be maintained.
I'm proud of the results, but the project broke me and I don't want to touch it anymore.

## Disclaimer
While the compiler works, I do not recommend using it for serious or production projects.
It is primarily intended for educational purposes.

## Purpose
The main value of this project is reading the source code to understand how a compiler can be built from scratch.
Unlike other compilers, this one is relatively minimal, so there is not a lot of bloat or weird magic.
But the code is not always clean, and some comments are very explicit. Sorry :(
